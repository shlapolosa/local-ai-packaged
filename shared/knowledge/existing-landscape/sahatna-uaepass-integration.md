# UAE Pass Integration

## Overview
UAE Pass is a unified digital identity platform for UAE residents and citizens that provides secure access to government and private sector services.

## Features
- Single sign-on solution
- Biometric verification
- Smart ID cards support
- Mobile credentials
- Unified digital identity across multiple platforms

## Integration Type
- External REST API
- Used by Identity Service Module

## Usage in Sahatna
- Patient authentication and login
- Patient logout
- Guest login
- Identity verification
