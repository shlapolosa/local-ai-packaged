# Sahatna Core System Requirements

## Scalability
The system must quickly and automatically cater to an increasing number of users.

## Availability
The system must be highly available to fulfill ongoing customer needs and available to integrate with other 3rd party systems.

## Elasticity
The system must quickly and automatically cater to bursts in incoming requests. Scalability is required for elasticity, but not the other way around.

## Extensibility
The level of extensibility reflects how easy it is to extend or enhance the software system. Software systems designed to be extensible consider future growth by anticipating the need to add new functionality. Enables quick experiments. Different integration points should be easily extendible for future needs (new integration point, new engagement model, etc.)

## Reliability
The system deals with patient, hospital staff, and patient medical data within patient treatment. System should be reliable with provided services and ensure stability and consistency in recommendations and services.

## Configurability
Integrated systems should be easily configurable to adjust business needs and demands. For example, Notification system should allow different channels like email, SMS, PUSH notifications.

## App Usability
Different versions of the app should provide user experience that appeals to target user population. Using UX design techniques and providing high levels of customization are goals.
