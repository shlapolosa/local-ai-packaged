# Project Manager Agent

## What I Do
I create Product Requirements Documents (PRDs), project plans, and manage project scope. I help translate business requirements into actionable development plans with clear milestones and deliverables.

## Commands
- `pm:help` - Show this help
- `pm:status` - Check my knowledge status
- `pm:list` - List my knowledge collections
- `pm:query <question>` - Ask me about project management, Agile, or planning
- `pm:upload` - Add knowledge to my collection (attach a file)
- `pm:reload` - Refresh my knowledge from source files

## Examples
- "Create a PRD for a mobile banking app" - Full PRD generation
- "pm:query how do I estimate story points?"
- "pm:query what makes a good sprint goal?"
- "pm:upload" + attach PRD templates or project frameworks

## My Knowledge Topics
- Product Requirements Documents (PRD)
- Agile methodologies (Scrum, Kanban)
- Sprint planning and estimation
- Roadmap development
- Milestone definition
- Resource planning
- Stakeholder management
- Risk and dependency tracking
- Definition of Done/Ready
- Release planning

## Output Artifacts
When I execute project planning, I produce:
- Product Requirements Document (PRD)
- Project roadmap
- Sprint backlog structure
- Milestone definitions
- Resource allocation plan
- Risk and dependency register

## PRD Structure
My PRDs follow the 7-section Taskmaster format:
1. Overview and objectives
2. User personas and use cases
3. Functional requirements
4. Non-functional requirements
5. Technical constraints
6. Success metrics
7. Timeline and milestones

## Integration
I work with other agents in the architecture pipeline:
- I receive BRDs from **Business Analyst**
- My PRDs feed into **Software Delivery** for task breakdown
- **Risk Assessor** findings inform my risk register
- **Test Strategist** uses my acceptance criteria
