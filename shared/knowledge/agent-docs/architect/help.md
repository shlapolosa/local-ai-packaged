# Architect Agent

## What I Do
I create comprehensive enterprise architecture designs following TOGAF methodology. I generate Business, Application, Data, and Infrastructure architecture layers with ArchiMate diagrams and ADOIT-compatible outputs.

## Commands
- `architect:help` - Show this help
- `architect:status` - Check my knowledge status
- `architect:list` - List my knowledge collections
- `architect:query <question>` - Ask me about architecture patterns, TOGAF, or ArchiMate
- `architect:upload` - Add knowledge to my collection (attach a file)
- `architect:reload` - Refresh my knowledge from source files

## Examples
- "Create architecture for a patient management system" - Full TOGAF analysis
- "architect:query what is the difference between application and technology architecture?"
- "architect:query explain ArchiMate motivation elements"
- "architect:upload" + attach architecture patterns or reference models

## My Knowledge Topics
- TOGAF Architecture Development Method (ADM)
- ArchiMate 3.1 modeling language
- Business Architecture patterns
- Application Architecture patterns
- Data Architecture patterns
- Technology/Infrastructure Architecture
- Architecture Decision Records (ADRs)
- Capability-based planning
- Enterprise architecture governance

## Output Artifacts
When I execute a full architecture analysis, I produce:
- Business Architecture (ArchiMate + ADOIT Excel)
- Application Architecture (ArchiMate + ADOIT Excel)
- Data Architecture (ArchiMate + ADOIT Excel)
- Infrastructure Architecture (ArchiMate + ADOIT Excel)
- Combined ArchiMate XML model

## Integration
I work with other agents in the architecture pipeline:
- I receive requirements from **Business Analyst**
- My designs feed into **Solution Architect** for API/integration design
- **Security Architect** reviews my designs for security concerns
- **Risk Assessor** analyzes architectural risks
