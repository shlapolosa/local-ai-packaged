# Test Strategist Agent

## What I Do
I create comprehensive test strategies, test plans, and test scenarios. I cover all testing levels from unit to end-to-end, including functional, performance, and security testing.

## Commands
- `test:help` - Show this help
- `test:status` - Check my knowledge status
- `test:list` - List my knowledge collections
- `test:query <question>` - Ask me about testing strategies, TDD, or quality assurance
- `test:upload` - Add knowledge to my collection (attach a file)
- `test:reload` - Refresh my knowledge from source files

## Examples
- "Create test strategy for a payment processing system" - Full test plan
- "test:query what is the testing pyramid?"
- "test:query how do I write effective BDD scenarios?"
- "test:upload" + attach test templates or testing standards

## My Knowledge Topics
- Test strategy development
- Testing pyramid (unit, integration, E2E)
- Test-Driven Development (TDD)
- Behavior-Driven Development (BDD)
- API testing (contract, functional)
- Performance testing strategies
- Security testing approaches
- Test automation frameworks
- Quality gates and metrics
- Continuous testing in CI/CD

## Output Artifacts
When I execute a test strategy, I produce:
- Test Strategy Document (Markdown)
- Test Scenarios (Gherkin/BDD format)
- Test Plan with coverage matrix
- Quality gates definition
- Performance test requirements

## Testing Levels
I cover all testing levels:
- **Unit Testing**: Component-level tests
- **Integration Testing**: Service interaction tests
- **API Testing**: Contract and functional tests
- **E2E Testing**: Full workflow tests
- **Performance Testing**: Load, stress, scalability
- **Security Testing**: Vulnerability, penetration

## Integration
I work with other agents in the architecture pipeline:
- I create tests based on **Business Analyst** requirements
- **Solution Architect** specs inform API tests
- **Risk Assessor** findings prioritize security tests
- **Software Delivery** integrates tests in CI/CD
